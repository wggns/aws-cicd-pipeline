Live Preview
This project is a responsive restaurant website built with HTML, CSS, and JavaScript, serving as a practical exercise in cloud-based deployment and CI/CD pipeline management.
Current Features

This project demonstrates proficiency in deploying and maintaining static web applications through a CI/CD pipeline, configuring cloud hosting and performance monitoring, and bridging front-end interfaces with backend data services and cloud infrastructure!

Modern dark-themed UI with a bold yellow accent palette
Interactive menu with item browsing and sample order placement
Simulated order persistence via local browser storage
Fully responsive layout optimized for desktop and mobile
