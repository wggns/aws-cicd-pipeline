This project is a currently a responsive restaurant website built using HTML, CSS, and JavaScript.
Although I didn’t develop the entire codebase from scratch, I understand how to modify, configure, and extend it for my own use primarily html/css.

The purpose of this project was for me to practice cloud-based website deployment and monitoring through a CI/CD pipeline. It serves as a practical exercise in managing front-end updates, testing live deployments, and exploring the data handling workflow.

 The Current Features

Modern dark-gray and yellow restaurant theme

Interactive menu where the user can view items and place sample orders

Local data persistence using browser storage (simulated order saving)

Responsive design optimized for desktop and mobile

In Progress

I’m currently configuring real time data storage so that orders submitted through the website can be received and processed in real time through a connected cloud service.

Purpose

This project will demonstrate my ability to:

Deploy and update static web applications through a CI/CD pipeline

Configure cloud hosting and monitoring

Integrate front-end development with backend and data services
